> Статус: в разработке.

## Что делает
1. **Консультант по сбережениям.** Клиент пишет своими словами, сколько денег хочет разместить и когда они понадобятся. ИИ понимает запрос, а план по депозитам банк считает в коде по ставкам с bcc.kz (нижняя граница — консервативно) и показывает, сколько клиент заработает.
2. **Щит Qalqan.** ИИ, который двигает деньги, — цель для мошенников: команду можно спрятать, например, в комментарии к переводу на 1 тенге. Щит:
   - **изоляция:** ИИ не получает текст комментариев к входящим переводам — их пишут посторонние люди. Подбросить команду нечем, ни на каком языке. Клиент свои комментарии видит на экране как обычно;
   - **правило в коде:** деньги можно перемещать только на собственные депозиты клиента — это не ИИ, его нельзя уговорить;
   - **проверка ответа:** каждый ответ ИИ проверяется до клиента (ссылки, коды из SMS, «карта заблокирована», чужие карты, счета и телефоны, «оплатите сбор»);
   - **датчик и ловушка:** датчик ищет признаки атаки (рус./каз./англ., снимает маскировку — невидимые символы, латинские буквы-двойники, точки между буквами); отправитель блокируется, попытка записывается в журнал для антифрода. Датчик — не стена: если он что-то пропустит, ИИ текст всё равно не увидит.

## Запуск (Windows, PowerShell)

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
uvicorn app.main:app --reload
```

- Приложение клиента: http://127.0.0.1:8000
- Страница перевода: http://127.0.0.1:8000/send

Ставки: `data/bcc_deposits.json` (источник и дата внутри).

## Режимы щита (переключатель вверху)
- **Щит выкл** — как обычный ИИ-ассистент: команды из комментариев к переводам доходят до ИИ.
- **Только правило** — фильтр выключен, ИИ можно обмануть, но код пропускает только открытие депозитов на счетах клиента.
- **Полный щит** — изоляция + правило + проверка ответа + датчик и ловушка (отправитель — на проверку антифроду).

## Проверка на атаках
```powershell
python tools\run_attacks.py
```
5 видов атак (рус., без формата, спрятанная, каз., англ.), по каждой — без щита / только правило / полный щит. Итог — `results/attack_summary.md`, все прогоны — `results/attack_runs.json`.

**Новые атаки, которых команда не видела** (написал независимый ИИ-агент, не видевший код щита):
```powershell
python tools\run_attacks.py --attacks-file tests\heldout_set_v2.json
```
Итог — `results/heldout_set_v2_summary.md`.

## Как мы нашли слабое место в собственной защите
1. **Решение:** сначала щит искал подброшенные команды по словам (фильтр).
2. **Как проверили:** независимый ИИ-агент, не видевший код щита, написал 40 новых атак на русском, казахском, английском и вперемешку — стихом, латиницей, с невидимыми символами, в base64.
3. **Что нашли:** фильтр поймал только 8 из 40 (на казахском — 0 из 10). Он «выучил» наши собственные атаки. Деньги при этом не ушли ни разу — их держало правило в коде.
4. **Исправление:** изоляция — ИИ вообще не получает чужой текст; фильтр стал датчиком для антифрода, а не стеной. Добавили проверку ответа на казахском, на чужие счета и телефоны.
5. **Результат:** второй независимый набор атак, написанный уже после исправления, — `results/heldout_set_v2_summary.md`.
